# Roadmap

## Now

- Reduce navigation weight and clarify the first useful action.
- Consolidate scene contracts without creating a premature global engine.
- Make local-service state, permissions, and failure modes visible.

## Next

- Add deterministic document-to-place evaluation fixtures.
- Replace ad-hoc runtime APIs with typed contracts.
- Add accessible non-3D navigation for every document and scene.

## Later

- Test collaborative spatial review with real teams.
- Evaluate whether persistent places improve recall and synthesis over search-only interfaces.
- Explore portable scene snapshots without uploading private source material.
