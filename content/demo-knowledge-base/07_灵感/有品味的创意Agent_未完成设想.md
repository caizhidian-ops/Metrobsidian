# 有品味的创意 Agent（未完成设想）

我不满足于让模型把像素补齐得更像。模型会组合已有形式，但“为什么选这个元素、为什么不选另一个、哪里应该留白”仍然需要一层明确的创意判断。

当时我把流程写成了五段：需求先变成带参考、方向和禁区的 brief；第一轮不是只出一张，而是出候选并比较；根据不好的原因改提示或改参考；再做文字、尺寸、品牌元素等常规检查；最后交付成能继续改的文件。

我给“有品味”和“俗套”做过一个很主观的对照：前者每个元素有理由，删掉会损失信息；前者在约束里偶尔破例；前者承认材质、时间和文化来源。相反的一面则是什么都舍不得删、没有约束、像通用拼贴。

这不是一个已经验证的产品定义。尤其“模型能否判断美感”仍然悬而未决。但它保留了我不想只做确定性海报工具的原因。
