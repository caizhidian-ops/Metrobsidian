# 建筑映射：知识类型 → 3D 场景建筑

知识库**按个人知识类型独立组织**（01_工作 / 02_学习 / 03_案例 / …），与 3D 场景中的建筑**解耦**。
建筑只是展示形态：这份映射表供展示层（3D 地图）把知识路由到对应建筑，改映射不影响知识库本身。

| 建筑（3D 场景） | 知识类型 | 说明 |
| --- | --- | --- |
| 公司 | 01_工作 | 职业、项目、产品、创业 |
| 家庭 | 04_生活 | 家庭与日常、个人管理 |
| 学校 | 02_学习 | 学习、阅读、研究方法 |
| 医院 | 06_复盘 | 健康检查 / 体检（知识库健康检查归此） |
| 食堂 | 08_创作 | 内容、兴趣、测试记录 |
| 施工工地 | 01_工作 + 07_灵感 | 进行中的实验 / 在建项目 |

## 使用说明

- 映射不是一对一的硬绑定：一个知识文件可带多个标签，展示层按标签路由到多栋建筑。
- 网络案例的「建筑标签」见 [03_案例/案例索引.md](03_案例/案例索引.md)，仅作为 demo 展示时的默认入口。
- 修改此表 = 调整展示层，不移动知识库文件。
