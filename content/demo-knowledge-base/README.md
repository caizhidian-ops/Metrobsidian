# Demo knowledge base

This directory contains rewritten, sanitized Markdown used to demonstrate Metrobsidian's knowledge-to-place mapping. It is publishable example content, not a raw personal archive.

The folders represent common knowledge types such as work, learning, cases, life, health, reflection, ideas, and creation. The 3D buildings are a presentation layer; the mapping is documented in [`建筑映射.md`](./建筑映射.md).

New examples must remove or replace identifying combinations, precise locations, account information, private commercial data, credentials, and machine-specific implementation details. Prefer synthetic examples when the product behavior can be demonstrated without real personal material.
