# 公开改写说明

## 这次实际替换了什么

- 人名、前雇主、客户/合作方、城市、站点、账号、精确日期：改为角色、行业或阶段。
- 访问量、收入、定价、工资、服务报价、训练重量：改为数量级、相对变化或不带单位的趋势。
- 内部路径、供应商、接口、部署和原始链接：改为能力描述或删去。
- 书、论文、第三方 README 和截图：不转存正文；只留下我自己的阅读/使用判断。

## 保留下来的痕迹

- 原笔记的时间感，例如“这一轮”“上周”“后来又发现”。
- 不完整的推理链：问题、临时判断、证据不足、下一步。
- 原始工作中出现过的结构：清单、对比、待办、失败原因和复盘。

公开版不以“打码后的原件”为目标，而以“别人能理解我如何工作，但无法还原原始对象”为目标。
