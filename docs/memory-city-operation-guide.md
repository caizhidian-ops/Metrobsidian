# 记忆城市操作手册

这份手册对应当前 `apps/city` 主地图与 `services/knowledge` 分类服务。

## 一、第一次启动

需要同时启动三部分：Ollama、本地知识服务、3D 地图。

### 1. 启动本地模型

确认 Ollama 中已有：

- `bge-m3`：把文件内容转换为向量，用于分类；
- `qwen3:8b`：为新聚类主题命名。

```powershell
ollama list
```

如 Ollama 没有自动在后台运行：

```powershell
ollama serve
```

### 2. 启动分类服务

在项目根目录打开 PowerShell：

```powershell
cd services/knowledge
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即正常。不要关闭这个窗口。

数据库与上传文件默认保存在 `services/knowledge/data/`；可用 `LKS_DATA_DIR` 改到其他目录。可扫描目录由 `LKS_ALLOWED_ROOTS` 明确授权。

### 3. 启动 3D 地图

再打开一个 PowerShell：

```powershell
cd apps/city
npm install
npm run dev
```

打开终端显示的本地地址，通常是 `http://127.0.0.1:5173/`。如果端口被占用，Vite 会显示新的端口，以终端实际地址为准。

## 二、最常用：把文件拖进城市

1. 打开主地图。
2. 从资源管理器选择一个或多个文件。
3. 拖到地图任意位置；画面出现“松开即可分类入城”后松手。
4. 也可以点击顶栏的“文件投递台”，用文件选择器导入。
5. 等待“正在解析并分类”完成。
6. 投递台下方会显示结果，例如 `论文笔记 → 学校`。

文件放入后，左侧对应建筑的文档数字会立刻增加。点击该建筑，再点“查看档案”即可阅读。

### 支持范围

- 所有文件格式都可以拖入并安全归档；服务只读取字节，不执行文件。
- TXT、Markdown、CSV、JSON、代码等文本格式会提取完整文本。
- DOCX、PPTX、XLSX 会使用本地 ZIP/XML 解析器提取文字。
- PDF 在本机装有 `pypdf` 时提取正文；没有时仍会归档，并根据文件名和类型分类。
- 图片、音频、视频、压缩包、安装包等暂不能读取正文，会根据文件名、扩展名和 MIME 类型分类。
- 单个文件上限为 128 MB。

### 分类规则

- 能找到最近建筑：先自动放入该建筑，置信度与理由保留在数据库中，之后仍可纠正。
- 无法可靠归入任何建筑：进入待发现主题池，不强塞进错误建筑。
- 同一内容重复拖入：按 SHA-256 去重，不复制第二份。

## 三、查看与使用已分类文件

1. 左侧选择“公司、家庭、学校、医院、食堂、施工工地”或新分类建筑。
2. 相机会飞到对应建筑。
3. 点击“查看档案”。
4. 在左侧文档列表选择文件，右侧查看内容。
5. 顶栏搜索框可按建筑名、文档标题和摘要检索。

当前无法提取正文的二进制文件会显示归档元数据，不会伪造正文。

## 四、批量扫描整个文件夹

拖放适合临时文件。要一次处理整个文件夹，打开：

`http://127.0.0.1:8000/docs`

按顺序调用：

1. `POST /api/sources/folders/select`，请求体填本地绝对路径；
2. 复制返回的 `id`；
3. `POST /api/sources/{source_id}/scan`，把路径参数换成上一步的 `id`；
4. `GET /api/placements/inbox` 查看待确认建议；
5. 使用 `confirm`、`correct` 或 `reject` 接口确认、纠正或拒绝。

文件夹扫描目前只主动扫描 `.md`、`.markdown` 与 `.txt`，且不改动源文件。拖放入口的格式范围更广。

## 五、让新主题长出建筑

只有真正无法归入现有建筑的文件才进入新主题池。至少积累 3 份相关材料后：

1. `POST /api/building-genesis/candidates` 生成候选；
2. `GET /api/building-genesis/candidates/{candidate_id}/preview` 预览；
3. `POST /api/building-genesis/candidates/{candidate_id}/confirm` 确认；
4. `POST /api/building-genesis/candidates/{candidate_id}/build` 创建建筑记录。

新建筑只会使用外围预留地块。地块规则会检查道路和河流，不允许建筑压住道路或长进河里。

## 六、地图操作

- 左键拖拽：旋转视角；
- 滚轮：缩放；
- 右键拖拽：平移；
- 数字键 `1–6`：聚焦核心建筑；
- `R`：返回城市总览；
- `Ctrl/Cmd + K`：打开搜索；
- 点击小地图标记：定位街区。

城市动态现在遵循以下规则：

- 小车沿闭合车道行驶和转弯，不在道路末端瞬移；
- 行人只走已验证的人行环路，不进入河流；
- 路灯有完整灯杆、灯罩和光源，夜间自动点亮；
- 核心建筑与未来建筑均使用统一避路、避河地块约束。

## 七、常见问题

### 投递台显示“上传失败”

确认知识服务窗口仍在运行，并访问 `http://127.0.0.1:8000/docs`。打不开通常表示后端未启动。

### 长时间停在“正在解析并分类”

确认 Ollama 正在运行，且 `ollama list` 中能看到 `bge-m3`。首次加载模型会比后续慢。

### 文件进入了不合适的建筑

这表示最近建筑匹配存在歧义。当前可以在 Swagger 中使用 `POST /api/placements/{id}/correct` 修正；后续产品界面会把纠正入口直接放到收件箱。

### 文件没有立刻长出新建筑

这是安全边界，不是故障。系统需要至少 3 份同主题的新颖材料形成稳定聚类，并且必须经过用户确认才创建新建筑。
